# 臺灣壽險市場地形劇場
**Life Insurance Terrain Theater · Taiwan**

以官方公開資料推演人口、家庭、所得結構如何重塑壽險市場的 3D 戰情劇場式資料敘事。

靈感：[関ヶ原山水図屏風](https://sekigahara.tenz.net/) 的 3D 戰情推演風格。

---

七幕敘事 · 全台 22 縣市

序章 → 人口之峰 → 高齡前線 → 家的縮影 → 財富山脈 → 未來推演 2070 → 三大戰場

---

三個版本：

- **原版**（`terrain.html`）— 跨螢幕調校完成的基礎版，90 秒。以 3D 地形劇場呈現全台 22 縣市，山脈高度與色相編碼人口、家庭、所得結構。
- **強化版**（`theater/terrain.html`）— 在原版基礎上加入運鏡空照、編碼讀法鍵、轉場光掃等動畫特效，100 秒。同樣以「會變色的島／地形」為主視覺。
- **人口生命劇場**（`people.html`）— 全新的「以人為主角」版本，主標《如果臺灣是 100 個人》，約 95 秒。

### `people.html`｜如果臺灣是 100 個人

與前兩版最大的差異：主視覺不是「會變色的地圖」，而是 **100 個站在 3D 臺灣島上的具象人形**（以 `THREE.InstancedMesh` 繪製、效能流暢）。人形依世代上色——幼年 0–14 暖綠／青壯 15–64 燈金／高齡 65+ 玫紅，人數＝官方年齡占比四捨五入，讓「人口結構」變成一支看得見、能感受的隊伍。

設計意圖是**同理與共鳴**：當時間軸 1990 → 2025 → 2070 推進，前排的孩子一個個退場、後排的長者站起變高、中段的青壯變薄，觀眾「親眼看見」世代重新洗牌，而非閱讀一張金字塔圖或儀表板。

七幕敘事：序（1990 年輕隊形）→ 一 青壯的高原（人口紅利、2012 青壯 74.2% 高峰）→ 二 隊形重組（2025 高齡破 20%、超高齡社會）→ 三 老化的前線（最老 臺北市／嘉義縣 vs 最年輕 新竹縣 的縣市對照）→ 四 家越來越小（戶量 4.19→2.78 人、單人家庭 6.5%→15.6% 的家庭縮影）→ 五 誰來撐住一位長者（扶老比 29→100 的具象扶養場景）→ 終 二〇七〇的隊形（官方中推估：近半是長者）。

實際資料（暖光）與官方推估（2025+，幽藍冷光＋半透明人形＋徽章）全程明確區分。資料同前兩版：內政部戶政司、國發會中推估（2024–2070）、主計總處家庭收支調查。控制：播放／暫停、倍速、旋轉縮放（OrbitControls）、點選縣市探索。
