# population.json 資料來源說明

- 取得日期：2026-06-11
- 資料性質：實際（actual）戶籍登記人口統計，非推估值
- 主來源：內政部戶政司全球資訊網「人口統計資料」快速下載（https://www.ris.gov.tw/app/portal/346 → https://www.ris.gov.tw/info-popudata/app/awFastDownload/toMain_panel）
- 下載方式：直接以 HTTP GET 下載 XLS 檔（URL 樣式 `https://www.ris.gov.tw/info-popudata/app/awFastDownload/file/{code}-00000.xls/{code}/00000/`），以 Python xlrd 解析
- 原始檔留存於 `raw/probe_{code}.xls`

## 各資料系列

### national.total / pct0_14 / pct15_64 / pct65（1990–2025，年底數）
- 來源檔：`y1s4`「年底人口三階段年齡結構、依賴比、老化指數及扶養比」（工作表「三階段人口」，民國35年–114年）
- URL：https://www.ris.gov.tw/info-popudata/app/awFastDownload/file/y1s4-00000.xls/y1s4/00000/
- 留存檔名：`raw/probe_y1s4.xls`
- 清理方式：取各年「年底人口數」總計與 0–14、15–64、65+ 三階段人口數；百分比以人口數重新計算並四捨五入至小數一位（與官方公布之百分比一致）。已驗證三階段人口數相加等於總計。

### national.births / deaths（1990–2025，按登記日期之全年數）
- 來源檔：`y1s3`「人口總數、年增加、自然增加、出生、死亡數及其比率」（工作表「全國」，民國46年–114年）
- URL：https://www.ris.gov.tw/info-popudata/app/awFastDownload/file/y1s3-00000.xls/y1s3/00000/
- 留存檔名：`raw/probe_y1s3.xls`
- 交叉驗證：與 `y2s1`「出生數按性別及粗出生率」（raw/probe_y2s1.xls）及 `y3s1`「死亡數按性別及粗死亡率」（raw/probe_y3s1.xls）逐年比對，1990–2025 完全一致；年底人口總數與 y1s4 比對，1972 年以後完全一致（1971 年以前因臺閩地區涵蓋範圍差異而不同，不在輸出範圍內）。

### national.medianAge
- 省略。戶政司快速下載區無年度「年齡中位數」官方序列表（y1s8「人口年齡結構重要指標」僅含 0–4／0–6／0–11／12–17／20+／65+ 結構），為避免自行推算造成與官方公布值差異，不輸出此欄位。

### counties（22 縣市，2000–2025，年底數）
- 來源檔：`y0s1`「各縣市人口數按性別及五歲年齡組分」（每年一個工作表，民國63年–114年；本檔取民國89–114年）
- URL：https://www.ris.gov.tw/info-popudata/app/awFastDownload/file/y0s1-00000.xls/y0s1/00000/
- 留存檔名：`raw/probe_y0s1.xls`
- 清理方式：
  - 取各縣市「計」（男女合計）列；0–14 = 0歲+1–4歲+5–9歲+10–14歲；15–64 = 15–19…60–64 十組相加；65+ = 65–69…100+ 八組相加。已逐縣市驗證三段相加等於總計，且各年 22 縣市總和等於全國總數（2000、2010、2025 抽驗 diff=0）。
  - 百分比與 agingIndex（老化指數 = 65+人口/0–14人口×100）由上述人口數計算，四捨五入至小數一位。
  - 縣市改制對齊（2000–2009 年資料按改制後行政區合併，使全期間為一致的 22 縣市）：臺北縣→新北市；桃園縣→桃園市（2014-12-25 改制，民國103年底起原表即為桃園市）；臺中縣+臺中市→臺中市；臺南縣+臺南市→臺南市；高雄縣+高雄市→高雄市（2010-12-25 改制，民國99年底起原表即為新制）。
  - 縣市名稱一律使用官方「臺」字寫法。
- 交叉驗證：與 `y0s5`「各縣市年底三階段年齡人口數、百分比及其扶養比」（raw/probe_y0s5.xls，民國96–114年）抽驗 2007 宜蘭縣、2011 新北市、2025 高雄市之總計與 65+ 人口數，完全一致。

## 已知限制
- 為「戶籍登記人口」，與主計總處普查之「常住人口」概念不同。
- 出生／死亡數採「按登記日期」統計（戶政司另有按發生日期版本，數值略異）。
- 縣市 2000–2009 年為改制後行政區之合併回溯值，非當年法定行政區數值。
- 年齡中位數未輸出（官方無現成年度序列）。
